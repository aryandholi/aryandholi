### Projects

#### [Smart City Real-Time Data Pipeline](https://github.com/aryandholi/Smart-City-End-To-End-Project)
> `Apache Kafka` &nbsp; `Apache Spark` &nbsp; `AWS S3 / Glue / Athena` &nbsp; `Docker` &nbsp; `Python`

A production-grade streaming pipeline that simulates a smart city IoT network — ingesting live vehicle telemetry, GPS coordinates, weather, and emergency events through Kafka, processing and partitioning the data with Spark Structured Streaming, and landing it on AWS for serverless SQL querying via Athena. Fully containerized and reproducible.

---

#### [Real Estate Data Orchestrator](https://github.com/aryandholi/Real-Estate-Data-Orchestrator)
> `Apache Kafka` &nbsp; `PySpark` &nbsp; `Apache Cassandra` &nbsp; `OpenAI GPT-3.5` &nbsp; `Playwright` &nbsp; `Docker`

An end-to-end AI-driven data pipeline that scrapes live property listings from Zoopla using Playwright with proxy rotation, passes raw HTML through GPT-3.5 Turbo for structured JSON extraction, streams records through Kafka, and persists the output in Cassandra via a PySpark micro-batch processor. Designed for scale and fault tolerance.

---

#### [AI News Aggregator](https://github.com/aryandholi/AI-News-Aggregator)
> `Python` &nbsp; `Gemini / Claude API` &nbsp; `PostgreSQL` &nbsp; `Docker` &nbsp; `YouTube API` &nbsp; `RSS`

An autonomous content intelligence pipeline that aggregates YouTube transcripts and RSS articles, applies LLM-based summarization (Gemini 1.5 Pro / Claude 3.5 Sonnet), and delivers a personalized daily email digest. Stateful deduplication via PostgreSQL ensures no content is processed twice. Deployed on Render.
